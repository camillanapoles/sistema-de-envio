# sistema-de-envio
Sistema pessoal de entrega: garante que projetos terminem em artefatos reais,
fora de qualquer sessão de IA, com validação externa e cobrança autônoma.

## Índice
| Arquivo | Função |
|---|---|
| 00-CONTRATO-DE-ENVIO.md | Template obrigatório de todo projeto |
| 01-PORTFOLIO-REAL.md | Placar único: ENVIADOS / EM VOO / FILA / MORTOS |
| 02-WIP-BOARD-E-RITUAIS.md | Rituais semanais e regras de retomada |
| 03-CONTRATO-CATALOGO.md | Primeiro contrato assinado (campo 5 pendente) |
| 04-PONTE-KIMI.md | Protocolo Actions ↔ Kimi (gates, WAL, fila) |
| 05-GOVERNANCA.md | Correções estruturais dos erros diagnosticados |
| 06-DIARIO-CORRECAO.md | WAL das correções aplicadas e pendências |
| CATALOGO-AGENTES-SDK.md | Primeiro artefato real entregue |

## Automação ativa
- **Cobrador**: toda segunda 07h (issue) + dia 1 do mês (métrica)
- **Gate Hook**: comente `/kimi <pedido>` ou rotule `kimi-gate` em qualquer issue
